... but hey, better late than never!

So I was just complaining about how PuTTY doesn't seem to handle SSH keys (e.g. AWS, Azure) very well, and then I came to (belated) realization that because rsync can be used in Windows via [Cygwin](http://cygwin.com/), so can ssh.

Now I don't waste time in a UI managing PuTTY profiles, generating PPKs, or [fidding with regedit.exe to clean up cached host fingerprints]({{< ref "2017-05-24-clear-cached-puttys-ssh-keys" >}}).

Try Cygwin, today.
