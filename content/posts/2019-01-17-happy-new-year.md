New year, new technology then!

I've been a long-time WordPress user. I create my draft using a good text editor (e.g., `vim`), then copy/paste into WordPress's web UI when satisfied; i.e., I don't use WordPress as intended: writing, editing and publishing directly in their UI proper. Plus I do format text in __bold__, _italic_, or `code` sometimes. These don't carry over upon copy/paste, and so I've decided to stop.

Of late I've been writing in [Markdown](https://daringfireball.net/projects/markdown/syntax). It's like HTML, without all the pedantic details about opening/closing tags, and this is my first post.
